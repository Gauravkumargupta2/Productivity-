# Productivity-
Features
Task management: add, edit, complete, and delete tasks with priorities and due dates
Habit tracker: build daily streaks and see consistency over time
Focus timer: Pomodoro-style sessions with short and long breaks
Progress dashboard: charts for daily, weekly, and monthly productivity
Categories and tags: organize work, study, and personal goals
Dark and light mode
Responsive design: works on desktop, tablet, and mobile
Local persistence: data is saved so it's there when you come back
Tech Stack
Layer	Technology
Frontend	HTML, CSS, JavaScript (or React)
Styling	CSS3 / Tailwind CSS
Charts	Chart.js

Getting Started
Prerequisites
A modern web browser
Node.js 18+ (only if using a build step or backend)
Installation
bash
# Clone the repository
git clone https://github.com/your-username/productivity-tracker.git

# Move into the project folder
cd productivity-tracker

# Install dependencies (if applicable)
npm install

# Start the development server
npm start

If it's a plain HTML/CSS/JS project, just open index.html in your browser.

Usage
Add a task: type a title, set a priority and due date, then press Add.
Start a focus session: choose a task and start the timer.
Track habits: tick your habits each day to grow your streak.
Review progress: open the dashboard to see completion rates and focus hours.
